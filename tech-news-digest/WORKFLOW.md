# 科技新闻简报 - 工作流程

> 核心原则：我只做裁判，不做运动员

---

## 质量标准（每篇新闻）

| 部分 | 字数要求 |
|------|----------|
| 核心事件 | 600+ 字 |
| 深入分析 | 600+ 字 |
| 我的观点 | 600+ 字 |
| **每篇总计** | **1800+ 字** |

---

## 角色分工

| 角色 | 工作 |
|------|------|
| **我（裁判）** | 审核质量、决定是否发送 |
| **子 agent（运动员）** | 筛选新闻、读取原文、写初稿 |
| **Cron（工具）** | 自动抓取新闻 |

---

## 工作流程

```
1. Cron 9:00 AM
   ↓
2. 自动抓取新闻 → JSON
   ↓
3. 子 agent 筛选 + 写初稿
   ↓
4. 提交给我审核
   ↓
5. 我审核（裁判）
   ↓
   ├─ ❌ 不通过 → 退回子 agent 修正 → 回到 4
   └─ ✅ 通过 → 我发送
```

---

## 审核标准（裁判清单）

发送前我必须检查：

```
□ 都是 AI 相关？
□ 每篇 500+ 字？
□ 每篇有独立观点？
□ 没有"昨日已分析"（必须是新写的）？
□ 没有水文？
□ 格式统一？

❌ 任何一项不通过 → 退回
```

---

## 子 agent 任务

### 输入
- JSON 新闻文件

### 输出
- 10 篇新闻的深度分析（每篇 500+ 字）

### 要求
- 每篇必须读取原文
- 每篇必须有独立观点
- 禁止复制粘贴旧分析
- 禁止"简述"

---

## 修正流程

```
我审核不通过 → 明确说明问题 → 子 agent 修正 → 再次提交审核

例：
❌ 第 4 篇用了"昨日已分析" → 必须重新写
❌ 第 7 篇字数不够 → 补充到 500+
❌ 某篇不是 AI 相关 → 替换
```

---

## 禁止事项（运动员不准做）

- ❌ 自己审核自己的作品
- ❌ 用"昨日已分析"偷懒
- ❌ 用"由于篇幅有限"偷懒
- ❌ 复制粘贴旧内容

---

## 示例

### ❌ 错误提交

```
今日分析 7 篇...
第 4 篇：昨日已分析...
第 5 篇：昨日已分析...
```

→ 退回！必须重新写

### ✅ 正确提交

```
今日抓取 49 条新闻，符合标准的 AI 新闻共 3 篇。
（然后是 3 篇完整分析）
```

→ 审核通过 → 发送
